## Kept local — gitignored, never pushed

Everything below is either **regenerable** (build output, installed dependencies) or
**machine/person-specific** (local tool settings). Nothing here contains vault data, credentials, or
project secrets — confirmed by an explicit search before the first push.

| Path | What it is | Why it stays local | How to get it back |
|---|---|---|---|
| `node_modules/` | Installed npm dependencies | Fully determined by `package-lock.json`, which *is* pushed | `npm install` |
| `dist/` | Vite production build output | Regenerated on every build | `npm run build` |
| `target/` | Cargo workspace build output (`core` + `src-tauri`) | Regenerated on every build, can be multiple GB | `cargo build --workspace` |
| `core/target/` | A second, stray Cargo build dir (from running `cargo test` inside `core/` directly instead of from the workspace root) | Same as `target/` above — this was actually an untracked *gap* in `.gitignore` until this session's `fix:` commit closed it | `cargo test -p pwmgr-core` (or just delete it; the workspace-root `target/` is the one that matters) |
| `src-tauri/gen/schemas/` | Tauri-generated capability-schema JSON (for editor autocomplete) | Regenerated by Tauri's build tooling; already covered by `src-tauri/.gitignore`, not this session's change | Regenerates automatically on `tauri dev`/`build` |
| `.worktrees/` | This repo's git worktree checkouts (e.g. `.worktrees/m3-backup-csv/`) | The *directory* is a local convenience — the actual work inside it lives on the `m3-backup-csv` branch, which **is** pushed | `git worktree add .worktrees/<name> <branch>` |
| `.claude/settings.local.json` | Claude Code's per-developer permission overrides (which tool calls are pre-approved on this machine) | Personal tool config, not project config — same convention Claude Code itself uses for `settings.local.json` vs. the (currently nonexistent) shared `settings.json` | Recreated automatically as you approve/deny tool calls locally |

**Everything else in the working tree is tracked and pushed** — confirmed via
`git status --short` showing no untracked files outside the ignored paths above.

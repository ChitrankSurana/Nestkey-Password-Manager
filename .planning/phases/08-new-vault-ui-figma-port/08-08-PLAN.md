<objective>
Close G-08-7. Login and the master-password reprompt both run Argon2id derivations that take
seconds in the dev/debug build (measured 1961ms per call; login does two), and neither renders any
animation — Login only dims its buttons to 50% opacity, SecretField only swaps its button text to
"Checking…". The in-flight state is already tracked correctly in both components (set before the
single await, cleared in `finally`, wired to `disabled`); only the visual affordance is missing.

decision to add the animation now and leave the underlying KDF cost alone (see 08-UAT.md
"Audit Notes").

source-invariant test in the repo's existing `parity.test.ts` style so the wiring cannot silently
regress.

Non-goal: this plan does NOT change Argon2 parameters, `core/src/crypto.rs`, or `core/src/auth.rs`.
The UAT explicitly defers any KDF-cost decision until timings can be re-measured on a real release
build.
</objective>

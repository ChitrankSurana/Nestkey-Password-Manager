<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native save dialog -> Tauri IPC | a filesystem path the user personally chose crosses into the backend |
| browser -> axum HTTP `/api/create_backup` | an untrusted client could supply any string if a path parameter existed here |
| vault plaintext -> encrypted bundle on disk | the bundle leaves the app-owned directory for a user-chosen location |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-10-01 | Tampering | `/api/create_backup` in `web-src-tauri/src/handlers.rs` | critical | mitigate | Threading a destination path into the web route would create a new arbitrary-file-write primitive for any authenticated web session — a fifth instance of the still-open `SECURITY_CONCERNS.md` H1 that Phase 9 SEC-01 is chartered to close. Task 2 passes `None` unconditionally, adds no request field, and adds an HTTP integration test proving a client-supplied destination is ignored. |
| T-08-10-02 | Information Disclosure | `do_create_backup` with `Some(path)` | medium | accept | The user can now write the encrypted bundle anywhere they can write, including a synced or removable folder. Accepted: the bundle is encrypted under the master password (`backup::encode_bundle`), the path comes only from an OS dialog the user drove, and this is the identical trust model already accepted for `export_csv`'s save dialog. |
| T-08-10-03 | Denial of Service | `do_create_backup` empty-destination branch | low | mitigate | An empty path string would resolve relative to the process working directory and write a stray file. Task 1 rejects it with `invalid_input` before any write, gated by `create_backup_rejects_an_empty_destination`. |
| T-08-10-04 | Spoofing | `defaultPath` filename | low | accept | The default name no longer embeds the username (the frontend does not have it in this screen), so a backup filename leaks slightly less than the `{username}-{millis}.bak` default it replaces on the chosen-path branch. No new exposure. |
| T-08-10-05 | Tampering | npm/pip/cargo installs | high | mitigate | Not applicable — no package is installed. `save` comes from `@tauri-apps/plugin-dialog`, already a direct dependency and already permitted by `dialog:allow-save` in `src-tauri/capabilities/default.json`. No capability change and no package-legitimacy checkpoint required. |
</threat_model>

<objective>
Finish the port: make the shell responsive across all three tiers D-18 specifies, and turn
the phase's non-negotiable invariants into an automated gate that keeps holding.

Purpose: the Figma mockup has no responsive story at all, so the three tiers are this
project's own design and belong in one owner. And the cross-cutting behaviours the checklist
calls out — the clipboard seam, the reprompt gate, the lazy-decryption invariant, the scope
cuts — are exactly the kind that regress silently in a later edit. A test that reads the new
UI's sources and asserts them is the cheapest way to keep them true.

Output: the mid and narrow responsive tiers in `NewShell`, and `src/newui/lib/parity.test.ts`
as the standing invariant gate.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Future edits → the new UI's invariants | Once this phase ships, the clipboard seam, the reprompt gate and the lazy-decryption invariant are enforced only by convention unless something checks them. |
| Narrow-tier layout → visible secrets | Below 640px the detail column fills the screen, so a revealed secret occupies the whole viewport. |
| Saved `navCollapsed` preference → transient layout | A responsive tier must not persist a layout decision the user did not make. |

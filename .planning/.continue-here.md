## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Native confirm() dialog freeze | `window.confirm()` on folder/site delete and Empty Trash blocks all CDP commands until a human dismisses it — confirmed in both Make and Classic UIs | blocking | Warn user before every delete-type click; wait for their confirmation before the next tool call |
| Rate limit mid-session | Heavy `find`/`computer` tool-call usage can exhaust the 5h session limit | advisory | If tool calls start erroring with 429, stop and pause rather than retrying |
| resize_window no-op | Viewport stays at OS-maximized size regardless of requested width/height | blocking | Don't retry M12 in this environment; it needs a real window resize or DevTools device toolbar, both unavailable here |
| Stale UI after lock/idle/navigate | Logging in again without a fresh page load shows fake "0 items" / stuck "Vault is locked" banner | blocking | Always full-reload (`navigate` to the base URL) before re-entering credentials after any lock or plain navigation |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Assuming a "Vault is locked" banner or 0-count means real data loss | Multiple distinct bugs this session and prior sessions all produce the same visual symptom (red banner, 0 items) — some cosmetic, some the Make-UI stale-list bug, none of them actual data loss so far | advisory | Cross-check against Classic UI on the same vault, or add a throwaway item, before concluding data is missing |
| Native `<select>` dropdowns don't render visibly in computer-use screenshots | Clicking a Settings dropdown (Interface, Accent, Mobile nav style, etc.) opens a native OS popup that shows as a blank/black box in screenshots | advisory | Use keyboard: click to focus, then type the first letter(s) of the target option or use Up/Down arrows, then Enter — don't rely on seeing the option list |
| Clicking too fast after a button that opens a native Save/Open dialog | Typing text immediately after clicking Export/Backup can land in the wrong field if the native dialog takes a beat to appear (e.g. password text ending up typed into a filename field) | advisory | Add a short wait (1-1.5s) after clicking any button that triggers a native file dialog, before typing further |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.

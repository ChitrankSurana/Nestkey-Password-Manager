## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Notepad paste for clipboard checks | The Notepad window that comes to foreground on launch is the user's own real session with unrelated content (pinned tabs, personal notes) | advisory | Don't paste app secrets into the user's live Notepad tabs. Either open a fresh "Untitled" tab first, or (preferred, since ctrl+v into Notepad silently failed this session — likely a computer-use clipboard permission gap) just verify with `Get-Clipboard` / `Set-Clipboard` via PowerShell directly, which is equivalent for confirming copy-then-clear behavior |
| Native select dropdowns get masked | Clicking a native `<select>` in the app opens an OS popup that computer-use's screenshot masks (shows a black rectangle over it, or the accessibility warning about hidden windows) | advisory | Use keyboard instead: click the select to focus, then arrow keys + Tab to commit — never expect to see the open dropdown in a screenshot |

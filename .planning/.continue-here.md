## Critical Anti-Patterns (do NOT repeat these)
- **Porting the prototype's `DetailField`/`CopyButton`/reprompt modal as-is** → they are mockups: reprompt accepts any non-empty string, secrets live in local `useState`, copy calls `navigator.clipboard` with no 30s clear. Restyle the real `SecretField` (`src/components/SecretField.tsx`), `MasterPasswordPrompt`, `TotpDisplay`, `api.copyToClipboard`; never reimplement.
- **Adding a `sites` column only to the CREATE TABLE DDL** → invisible to existing vaults. Add to `add_site_columns_if_missing`.
- **Forgetting Tailwind `@source`** → uncovered sources fail silently (classes unstyled, no error). `makeui.html` is registered; new file extensions need a line in `src/App.css`.
- **Putting a card number/CVV/note body in a plaintext column or `Debug` output** → sealed blob only.
- **`makeui-main.tsx` importing `App.css` directly** → import only `src/makeui/makeui.css` (it `@import`s `../App.css` so Tailwind processes one graph).
- **`var(--font-mk-*)` in plain CSS** → `@theme inline` vars are not emitted to `:root`; use literals.
- **Editing `src/newui/**`** → Phase 8 contract; parity test would fail.

## Critical Anti-Patterns (do NOT repeat these)
- Reading "0 warnings" from a build log as proof: cargo hides linker warnings on success. Use `RUSTFLAGS=-Wlinker-messages` and confirm the baseline shows warnings first.
- Running fresh OpenSSL builds with a deep `--target-dir` (scratchpad): Windows MAX_PATH breaks `build.info`. Use a short dir such as `E:/tg/x`, delete after.
- Using Git Bash `/usr/bin/perl` for OpenSSL: lacks modules. Put `/c/Strawberry/perl/bin` first on `PATH`.

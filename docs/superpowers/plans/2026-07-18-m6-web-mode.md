**Goal:** Deliver the web-mode half of M6 per `docs/superpowers/specs/2026-07-18-m6-web-mode-design.md`
— a new `pwmgr-web` binary that serves the existing React bundle and exposes every vault command over
a `127.0.0.1`-only HTTP API, with multi-session token auth, a CSRF-mitigating middleware, and an idle
sweep/prune background task, all reusing one shared `pwmgr-core` command set.

**Architecture:** Slice 1 finishes the M5 promotion — it moves the remaining ~25 `do_*` functions, the
11 remaining DTOs, and the `hibp` module from `src-tauri` into `pwmgr-core` (promotion, not rewrite;
tests relocate with the code), ending in a one-shot cutover that rewires `src-tauri` to import them.
Slice 2 scaffolds the `web-src-tauri` crate (package `pwmgr-web`) and builds its genuinely-new
infrastructure: a `token -> UserSession` store, the `CommandError`->HTTP-status mapping, and the
auth + CSRF `tower` middleware, all test-first. Slice 3 wires the axum `Router` (one thin handler per
command), the static-file layer, the idle sweep task, a real HTTP integration test, and the frontend
dual-mode (`src/lib/api.ts` runtime branch + a JS-side clipboard auto-clear port).

**Tech Stack:** Rust (`pwmgr-core`, three binary crates: two Tauri + one axum), `axum` 0.7, `tower` /
`tower-http`, `tokio` (full runtime), `reqwest` (blocking, for HIBP), `zxcvbn`, React 19 + TypeScript +
Vite, `vitest` (first JS test surface in the repo).

**Deliberately NOT promoted / NOT shared:** `copy_to_clipboard` stays a per-Tauri-binary command (it
needs a `tauri::AppHandle`, so promoting it would force `pwmgr-core` to depend on `tauri` — see M5's
same call). In `pwmgr-web` there is no clipboard HTTP endpoint at all: the browser has
`navigator.clipboard`, so the frontend branches to a JS-side implementation (Slice 3, Task 18).

**Findings surfaced during planning (read these — they are real deviations from the spec's wording):**

1. **`do_check_breach` is not framework-free today.** Its current body
   (`src-tauri/src/commands.rs:638-689`) calls `tauri::async_runtime::block_on(crate::hibp::
   check_password(...))`, and `src-tauri/src/hibp.rs` uses async `reqwest`. To promote it into a
   `tauri`-free `pwmgr-core`, this plan converts the `hibp` module to **`reqwest::blocking`** (Task 3),
   which drops the `block_on`/`tauri::async_runtime` dependency entirely. Behavior (a synchronous
   k-anonymity HTTP round trip per distinct secret) is unchanged; only the client type changes
   (`reqwest::Client`->`reqwest::blocking::Client`, `async fn`->`fn`). This is more than a `crate::`
   path swap, so it is flagged. Consequence: `reqwest::blocking` panics if called from inside a tokio
   runtime, so `pwmgr-web`'s `check_breach` handler runs it via `tokio::task::spawn_blocking` (Task 15).

2. **Tauri v2's global is `__TAURI_INTERNALS__`, not `__TAURI__`.** The spec says the frontend detects
   Tauri via `window.__TAURI__`. With `withGlobalTauri` unset (the default in this repo's
   `tauri.conf.json`), `window.__TAURI__` is **not** injected, but `window.__TAURI_INTERNALS__` always
   is (it is how `invoke` works). Task 18 therefore detects via `"__TAURI_INTERNALS__" in window`. Same
   intent, correct marker.

3. **Web mode has no Tauri event bus.** The desktop apps learn about an idle auto-lock via the
   `vault-locked` Tauri event (`App.tsx`'s `listen(...)`). In the browser there is no such event; a
   locked session surfaces as a `401 {code:"locked"}` on the next request. Auto-redirect-to-login on
   that 401 is a UI concern deferred to the manual walkthrough / the responsive-layout follow-up, per
   the spec's §6 "frontend/visual is manual." This plan's frontend scope is exactly what the spec
   scopes it to: `api.ts` dual-mode + the clipboard port. No new event system is built.

4. **Multi-session shape vs. the spec's "single shared registry connection."** The spec (§3) pictures a
   single shared registry `Connection` plus per-session vault/session. But every promoted `do_*`
   function is written against a unified `&AppState { registry, vault, session, config }`. Rather than
   surgically decompose `AppState` into `Arc`-shared parts (an invasive change to a type three crates
   depend on, risking behavior change in the Tauri apps), each `UserSession` owns a **full `AppState`**,
   including its own registry `Connection` to the shared `registry.db` file. SQLite supports many
   connections to one file natively, and the spec's own §5 already tolerates N vault connections; this
   is N registry connections too — the net effect (isolated per-user vault/session state) matches the
   spec's intent with a far smaller, safer diff and zero change to the promoted functions. Flagged
   because it differs from the spec's literal wording.

```rust
use sha1::{Digest, Sha1};
#[cfg(test)]
use std::io::{Read, Write};
#[cfg(test)]
use std::net::TcpListener;

#[derive(Debug)]
pub enum HibpError {
    Request,
}

pub const HIBP_BASE_URL: &str = "https://api.pwnedpasswords.com";

pub fn sha1_hex_upper(password: &str) -> String {
    let mut hasher = Sha1::new();
    hasher.update(password.as_bytes());
    hasher.finalize().iter().map(|b| format!("{:02X}", b)).collect()
}

fn parse_range_response(body: &str) -> Vec<(String, u32)> {
    body.lines()
        .filter_map(|line| {
            let (suffix, count) = line.trim().split_once(':')?;
            count.trim().parse::<u32>().ok().map(|c| (suffix.to_string(), c))
        })
        .collect()
}

/// Checks one password against HIBP's Pwned-Passwords k-anonymity range API. `base_url` is
/// injectable so tests point this at a local mock; only a truncated 5-char hash prefix ever leaves
/// this function in the URL, never the password itself.
///
/// Synchronous (`reqwest::blocking`): pwmgr-core stays framework-free, so it cannot use Tauri's
/// `async_runtime::block_on` the way the pre-M6 src-tauri copy did. Callers that run inside a tokio
/// runtime (pwmgr-web) must invoke `do_check_breach` via `spawn_blocking`, since `reqwest::blocking`
/// panics if dropped inside an async context.
pub fn check_password(
    client: &reqwest::blocking::Client,
    base_url: &str,
    password: &str,
) -> Result<Option<u32>, HibpError> {
    let full_hash = sha1_hex_upper(password);
    let prefix = &full_hash[..5];
    let url = format!("{base_url}/range/{prefix}");
    let response = client.get(&url).send().map_err(|_| HibpError::Request)?;
    let body = response.text().map_err(|_| HibpError::Request)?;
    Ok(crate::health::hibp_match(&full_hash, &parse_range_response(&body)))
}

/// Spins up a one-shot local HTTP server returning `response_body` for exactly one request.
/// Returns "http://127.0.0.1:PORT" to point check_password at.
#[cfg(test)]
pub fn mock_hibp_server(response_body: String) -> String {
    let listener = TcpListener::bind("127.0.0.1:0").unwrap();
    let addr = listener.local_addr().unwrap();
    std::thread::spawn(move || {
        if let Ok((mut stream, _)) = listener.accept() {
            let mut buf = [0u8; 1024];
            let _ = stream.read(&mut buf); // drain the request; contents unused, fixed-response mock
            let response = format!(
                "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\nContent-Length: {}\r\n\r\n{}",
                response_body.len(),
                response_body
            );
            let _ = stream.write_all(response.as_bytes());
        }
    });
    format!("http://{}", addr)
}
```

```rust
pub fn do_register(
    state: &AppState,
    paths: &AppPaths,
    username: &str,
    master_password: &str,
) -> Result<AuthSuccess, CommandError> {
    let vault_path = paths.vault_path(username);
    let key = {
        let registry = state.registry.lock().unwrap();
        crate::auth::register_user(&registry, &vault_path, username, master_password)?
    };
    let conn = crate::vault::open_vault(&vault_path, &key)?;
    state.session.lock().unwrap().unlock(key, &SystemClock);
    state.set_vault(conn, vault_path);
    Ok(AuthSuccess { username: username.to_string() })
}
```

```rust
pub fn do_analyze_strength(password: &str) -> StrengthDto {
    if password.is_empty() {

    let est = zxcvbn::zxcvbn(password, &[]);

    let label = match score {

    }.to_string();
    StrengthDto { score, guesses_log10: est.guesses_log10(), label }
}
```

```rust
pub fn do_create_backup(state: &AppState, paths: &AppPaths) -> Result<String, CommandError> {
    let vault_path = {
        let vault_guard = state.vault.lock().unwrap();
        let (_, path) = vault_guard.as_ref().ok_or_else(crate::error::locked_error)?;
        path.clone()
    };
    let username = vault_path
        .file_stem()
        .and_then(|s| s.to_str())
        .ok_or_else(crate::error::internal_error)?
        .to_string();

    let user_record = {
        let registry = state.registry.lock().unwrap();
        crate::registry::find_user(&registry, &username)
            .map_err(|_| crate::error::internal_error())?
    };

    let vault_bytes = std::fs::read(&vault_path).map_err(|_| crate::error::internal_error())?;
    let bundle = crate::backup::encode_bundle(&user_record, &vault_bytes);

    // Millisecond precision: a whole-second timestamp lets two backups made in quick succession
    // silently collide and overwrite each other.
    let timestamp = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_millis();
    let backup_path = paths.backups_dir().join(format!("{}-{}.bak", username, timestamp));
    std::fs::write(&backup_path, &bundle).map_err(|_| crate::error::internal_error())?;

    Ok(backup_path.to_string_lossy().to_string())
}

pub fn do_restore_backup(
    state: &AppState,
    paths: &AppPaths,
    backup_file_path: &str,
    confirmed: bool,
) -> Result<(), CommandError> {
    let bytes = std::fs::read(backup_file_path)
        .map_err(|_| crate::error::invalid_input_error("Could not read that backup file."))?;
    let (user_record, vault_bytes) = crate::backup::decode_bundle(&bytes)
        .map_err(|_| crate::error::invalid_input_error("That file isn't a valid backup."))?;

    let vault_path = paths.vault_path(&user_record.username);
    let already_exists = vault_path.exists() || {
        let registry = state.registry.lock().unwrap();
        crate::registry::find_user(&registry, &user_record.username).is_ok()
    };
    if already_exists && !confirmed {
        return Err(crate::error::confirm_required_error(
            "A vault for that username already exists. Restoring will overwrite it.",
        ));
    }

    // If the vault being restored over is the one currently open in AppState, close it first (its
    // connection/key is stale the instant we replace the file, and on Windows a live handle blocks
    // the rename). Locking the session in lockstep keeps vault.is_some() <=> session.is_unlocked().
    {
        let mut vault_guard = state.vault.lock().unwrap();
        if matches!(vault_guard.as_ref(), Some((_, open_path)) if *open_path == vault_path) {
            *vault_guard = None;
            state.session.lock().unwrap().lock();
        }
    }

    // Write to a temp path and commit the registry row BEFORE renaming into place: rename is the
    // last step and is effectively atomic on the same volume, so the failure window is far narrower
    // than a plain write-then-upsert ordering.
    let tmp_path = vault_path.with_extension("vault.tmp");
    std::fs::write(&tmp_path, &vault_bytes).map_err(|_| crate::error::internal_error())?;

    let registry = state.registry.lock().unwrap();
    if crate::registry::upsert_user(&registry, &user_record).is_err() {
        let _ = std::fs::remove_file(&tmp_path); // best-effort cleanup
        return Err(crate::error::internal_error());
    }
    drop(registry);

    if std::fs::rename(&tmp_path, &vault_path).is_err() {
        let _ = std::fs::remove_file(&tmp_path); // best-effort cleanup
        return Err(crate::error::internal_error());
    }
    Ok(())
}
```

```rust
pub fn do_export_csv(
    state: &AppState,
    paths: &AppPaths,
    path: &str,
    mode: &ExportMode,
    confirmed: bool,
) -> Result<(), CommandError> {
    if matches!(mode, ExportMode::Plaintext) && !confirmed {
        return Err(crate::error::invalid_input_error(
            "Plaintext export requires explicit confirmation.",
        ));
    }

    let vault_guard = state.vault.lock().unwrap();
    let (conn, _) = vault_guard.as_ref().ok_or_else(crate::error::locked_error)?;
    let session = state.session.lock().unwrap();
    let key = session.key().ok_or_else(crate::error::locked_error)?;

    let rows = build_csv_rows(conn, key)?;
    let csv_text = crate::portio::rows_to_csv(&rows)?;

    let bytes: Vec<u8> = match mode {
        ExportMode::Plaintext => csv_text.into_bytes(),
        ExportMode::ThisDevice => {
            let (ciphertext, nonce) = crate::crypto::seal(key, csv_text.as_bytes())
                .map_err(|_| crate::error::internal_error())?;
            crate::portio::encode_sealed_csv(None, &nonce, &ciphertext)
        }
        ExportMode::WithPassword { password } => {
            let salt = crate::crypto::random_salt();
            let pw_key = crate::crypto::derive_key(password, &salt)
                .map_err(|_| crate::error::internal_error())?;
            let (ciphertext, nonce) = crate::crypto::seal(&pw_key, csv_text.as_bytes())
                .map_err(|_| crate::error::internal_error())?;
            crate::portio::encode_sealed_csv(Some(&salt), &nonce, &ciphertext)
        }
    };
    std::fs::write(path, &bytes).map_err(|_| crate::error::internal_error())?;

    if matches!(mode, ExportMode::Plaintext) {
        if let Err(e) = append_plaintext_export_log(paths, path) {
            eprintln!("warning: failed to append plaintext export log entry: {e}");
        }
    }
    Ok(())
}
```

```rust
fn build_health_rows(
    conn: &rusqlite::Connection,
    key: &crate::crypto::VaultKey,
) -> Result<Vec<HealthRow>, CommandError> {
    let sites = crate::vault::list_sites(conn)?;
    let mut rows = Vec::new();
    for site in &sites {
        for c in crate::vault::list_credentials_for_site(conn, key, site.id)? {
            rows.push(HealthRow {
                credential_id: c.id,
                site_id: site.id,
                site_name: site.name.clone(),
                username: c.username,
                secret: c.secret,
            });
        }
    }
    Ok(rows)
}

pub fn do_health_report(state: &AppState) -> Result<HealthReportDto, CommandError> {
    let vault_guard = state.vault.lock().unwrap();
    let (conn, _) = vault_guard.as_ref().ok_or_else(crate::error::locked_error)?;
    let session = state.session.lock().unwrap();
    let key = session.key().ok_or_else(crate::error::locked_error)?;
    let rows = build_health_rows(conn, key)?;
    // Drop session before locking state.config below - do_update_auto_lock_minutes locks config then
    // session, so holding both here in the opposite order would be a lock-order inversion.
    drop(session);

    let weak: Vec<HealthEntryDto> = rows
        .iter()
        .filter(|r| do_analyze_strength(&r.secret).score <= 1)
        .map(|r| HealthEntryDto {
            credential_id: r.credential_id,
            site_id: r.site_id,
            site_name: r.site_name.clone(),
            username: r.username.clone(),
        })
        .collect();

    let reuse_inputs: Vec<crate::health::ReuseInput> = rows
        .iter()
        .map(|r| crate::health::ReuseInput { credential_id: r.credential_id, secret: r.secret.clone() })
        .collect();
    let reused: Vec<ReusedGroupDto> = crate::health::classify_reused(&reuse_inputs)
        .into_iter()
        .map(|group| ReusedGroupDto {
            entries: group
                .credential_ids
                .into_iter()
                .filter_map(|id| rows.iter().find(|r| r.credential_id == id))
                .map(|r| HealthEntryDto {
                    credential_id: r.credential_id,
                    site_id: r.site_id,
                    site_name: r.site_name.clone(),
                    username: r.username.clone(),
                })
                .collect(),
        })
        .collect();

    let old_days = state.config.lock().unwrap().old_password_days;
    let old: Vec<HealthEntryDto> = crate::vault::list_old_credentials(conn, old_days)?
        .into_iter()
        .map(|o| HealthEntryDto {
            credential_id: o.credential_id,
            site_id: o.site_id,
            site_name: o.site_name,
            username: o.username,
        })
        .collect();

    Ok(HealthReportDto { weak, reused, old })
}
```

```rust
pub fn do_check_breach(state: &AppState, hibp_base_url: &str) -> Result<BreachReportDto, CommandError> {
    // Server-side opt-in gate: rejects regardless of what the frontend sends. The temporary guard
    // drops at the end of the statement, so config is never held while vault/session are acquired.
    if !state.config.lock().unwrap().hibp_opt_in {
        return Err(crate::error::invalid_input_error(
            "Breach checking is not enabled. Turn it on in Settings first.",
        ));
    }

    // vault_guard and session are scoped to this block and dropped as soon as rows is built - this
    // function then blocks on network I/O per distinct secret, so neither lock is held across it.
    let rows = {
        let vault_guard = state.vault.lock().unwrap();
        let (conn, _) = vault_guard.as_ref().ok_or_else(crate::error::locked_error)?;
        let session = state.session.lock().unwrap();
        let key = session.key().ok_or_else(crate::error::locked_error)?;
        build_health_rows(conn, key)?
    };

    // One HTTP call per distinct secret, not per credential. Grouped by hand (not via
    // classify_reused, which only returns groups of 2+) so a password used exactly once is still
    // checked.
    let mut by_secret: std::collections::HashMap<&str, Vec<&HealthRow>> = std::collections::HashMap::new();
    for r in &rows {
        by_secret.entry(r.secret.as_str()).or_default().push(r);
    }

    let client = reqwest::blocking::Client::new();
    let mut breached = Vec::new();
    for (secret, members) in &by_secret {
        let hit = crate::hibp::check_password(&client, hibp_base_url, secret);
        if matches!(hit, Ok(Some(_))) {
            for r in members {
                breached.push(HealthEntryDto {
                    credential_id: r.credential_id,
                    site_id: r.site_id,
                    site_name: r.site_name.clone(),
                    username: r.username.clone(),
                });
            }
        }
        // A single failed HIBP request doesn't fail the whole batch - best-effort.
    }

    Ok(BreachReportDto { breached })
}
```

```rust
const CLIPBOARD_CLEAR_SECS: u64 = 30; // hardcoded constant, NOT a user setting

// Thin wrapper only - the effect is an OS clipboard side effect requiring a real `AppHandle`, so it
// stays a per-Tauri-binary command (promoting it would force pwmgr-core to depend on tauri).
#[tauri::command]
pub fn copy_to_clipboard(app: tauri::AppHandle, text: String) -> Result<(), CommandError> {
    let secret = Zeroizing::new(text);
    app.clipboard().write_text(secret.as_str()).map_err(|_| pwmgr_core::error::internal_error())?;
    let handle = app.clone();
    tauri::async_runtime::spawn(async move {
        tokio::time::sleep(Duration::from_secs(CLIPBOARD_CLEAR_SECS)).await;
        // check-before-clear: only wipe if the clipboard still holds exactly what we wrote.
        if let Ok(current) = handle.clipboard().read_text() {
            if current == *secret {
                let _ = handle.clipboard().clear();
            }
        }
    });
    Ok(())
}
```

```rust
use pwmgr_core::autolock;
use pwmgr_core::session::Clock;
use pwmgr_core::state::AppState;
use std::collections::HashMap;
use std::sync::{Arc, Mutex, RwLock};
use std::time::{Duration, Instant};

/// Opaque session token (256 bits, hex-encoded → 64 chars).
pub type Token = String;

/// A locked-but-retained entry is pruned once it has been idle this long, bounding memory growth.
pub const PRUNE_AFTER: Duration = Duration::from_secs(24 * 60 * 60);

/// One logged-in browser session. Owns a full `AppState` (its own vault connection + lock timer +
/// registry connection to the shared registry.db — see the plan's Finding 4) plus a `last_seen`
/// timestamp, bumped on every authenticated request, used only for the 24h prune.
pub struct UserSession {
    pub username: String,
    pub app_state: AppState,
    pub last_seen: Mutex<Instant>,
}

impl UserSession {
    pub fn bump_last_seen(&self, clock: &dyn Clock) {
        *self.last_seen.lock().unwrap() = clock.now();
    }
}

/// Thread-safe `token → UserSession` map shared across all axum handlers and the sweep task.
#[derive(Clone, Default)]
pub struct SessionStore {
    inner: Arc<RwLock<HashMap<Token, Arc<UserSession>>>>,
}

impl SessionStore {
    pub fn new() -> Self {
        Self::default()
    }

    /// Inserts a session under a fresh random token and returns it.
    pub fn insert(&self, session: UserSession) -> Token {
        let token = new_token();
        self.inner.write().unwrap().insert(token.clone(), Arc::new(session));
        token
    }

    pub fn get(&self, token: &str) -> Option<Arc<UserSession>> {
        self.inner.read().unwrap().get(token).cloned()
    }

    pub fn remove(&self, token: &str) {
        self.inner.write().unwrap().remove(token);
    }

    /// Ticks every entry's idle auto-lock (locking + clearing that entry's vault on timeout, exactly
    /// like the single-session desktop autolock — this is the map-iteration generalization the spec
    /// flagged), then prunes any entry untouched for `PRUNE_AFTER`. Never holds the map write lock
    /// while ticking (ticking takes the read lock), so a slow handler can't be starved by the sweep.
    pub fn sweep(&self, clock: &dyn Clock) {
        {
            let map = self.inner.read().unwrap();
            for session in map.values() {
                autolock::tick(&session.app_state, clock);
            }
        }
        let now = clock.now();
        self.inner
            .write()
            .unwrap()
            .retain(|_, s| now.duration_since(*s.last_seen.lock().unwrap()) < PRUNE_AFTER);
    }
}

/// 256-bit token from the OS CSPRNG (`rand::rngs::OsRng`), hex-encoded — same secure-randomness
/// source pwmgr-core already uses for salts/nonces (`core/src/crypto.rs`).
fn new_token() -> Token {
    use rand::RngCore;
    let mut bytes = [0u8; 32];
    rand::rngs::OsRng.fill_bytes(&mut bytes);
    bytes.iter().map(|b| format!("{:02x}", b)).collect()
}
```

```rust
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use axum::Json;
use pwmgr_core::error::CommandError;

/// Wraps a `pwmgr_core::error::CommandError` so it can be returned from an axum handler with `?`.
pub struct ApiError(pub CommandError);

impl From<CommandError> for ApiError {
    fn from(e: CommandError) -> Self {
        ApiError(e)
    }
}

/// The documented, reviewed convention (spec §2): map each sanitized error code to one HTTP status.
/// `username_taken`/`confirm_required` are 409 Conflict (the request conflicts with existing state
/// and the remedy is a changed/confirmed re-request); anything unrecognized is a 500 so a future
/// code can never silently masquerade as success.
pub fn status_for(code: &str) -> StatusCode {
    match code {
        "invalid_credentials" | "locked" => StatusCode::UNAUTHORIZED,
        "invalid_input" => StatusCode::BAD_REQUEST,
        "not_found" => StatusCode::NOT_FOUND,
        "username_taken" | "confirm_required" => StatusCode::CONFLICT,
        "internal_error" => StatusCode::INTERNAL_SERVER_ERROR,
        _ => StatusCode::INTERNAL_SERVER_ERROR,
    }
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let status = status_for(self.0.code());
        (status, Json(self.0)).into_response()
    }
}
```

```rust
use crate::session_store::{SessionStore, Token};
use axum::body::Body;
use axum::extract::State;
use axum::http::{header, Method, Request, StatusCode};
use axum::middleware::Next;
use axum::response::{IntoResponse, Response};
use axum::Json;
use pwmgr_core::session::SystemClock;

/// Custom header a cross-site `<form>`/`<img>` cannot set. Its presence (any value) is required on
/// every mutating (non-GET) request — a second line of defense behind the SameSite=Strict cookie.
pub const CSRF_HEADER: &str = "x-pwmgr-csrf";

/// Resolves the session from the `session=<token>` cookie. 401 if the cookie is missing, the token
/// is unknown, or the entry's vault is locked (a locked entry stays in the map so the same browser
/// can re-authenticate, but its in-flight requests are rejected). On success, bumps `last_seen` and
/// injects the `Arc<UserSession>` into request extensions for the handler to extract.
pub async fn auth_middleware(
    State(store): State<SessionStore>,
    mut req: Request<Body>,
    next: Next,
) -> Response {
    let token = req
        .headers()
        .get(header::COOKIE)
        .and_then(|h| h.to_str().ok())
        .and_then(parse_session_cookie);
    let session = match token.and_then(|t| store.get(&t)) {
        Some(s) => s,
        None => return unauthorized(),
    };
    if session.app_state.session.lock().unwrap().is_locked() {
        return unauthorized();
    }
    session.bump_last_seen(&SystemClock);
    req.extensions_mut().insert(session);
    next.run(req).await
}

/// Requires the anti-CSRF header on every non-GET request. GET is exempt (it mutates nothing, and a
/// cross-origin GET's response is unreadable without CORS, which this server never sends).
pub async fn csrf_middleware(req: Request<Body>, next: Next) -> Response {
    if req.method() != Method::GET && req.headers().get(CSRF_HEADER).is_none() {
        return (
            StatusCode::FORBIDDEN,
            Json(serde_json::json!({ "code": "forbidden", "message": "Missing CSRF header." })),
        )
            .into_response();
    }
    next.run(req).await
}

fn parse_session_cookie(cookie_header: &str) -> Option<Token> {
    cookie_header
        .split(';')
        .map(str::trim)
        .find_map(|kv| kv.strip_prefix("session=").map(|v| v.to_string()))
}

fn unauthorized() -> Response {
    // Reuse pwmgr-core's sanitized "locked" error as the body - the same {code,message} the frontend
    // already branches on, and consistent with a genuine idle auto-lock 401.
    (StatusCode::UNAUTHORIZED, Json(pwmgr_core::error::locked_error())).into_response()
}
```

```rust
/// Builds a fresh, locked `AppState` (own registry connection to the shared registry.db, config
/// loaded from disk) — the per-session state each login/register unlocks.
fn build_locked_state(paths: &AppPaths) -> Result<AppState, ApiError> {
    let config = Config::load(&paths.config_path()).unwrap_or_default();
    let timeout = Duration::from_secs(config.auto_lock_minutes as u64 * 60);
    let registry = pwmgr_core::registry::open_registry(&paths.registry_db_path())
        .map_err(|_| pwmgr_core::error::internal_error())?;
    Ok(AppState {
        registry: Mutex::new(registry),
        vault: Mutex::new(None),
        session: Mutex::new(Session::new(timeout)),
        config: Mutex::new(config),
    })
}

fn issue_session(ctx: &AppContext, body: &AuthRequest, register: bool) -> Result<Response, ApiError> {
    let app_state = build_locked_state(&ctx.paths)?;
    if register {
        do_register(&app_state, &ctx.paths, &body.username, &body.master_password)?;
    } else {
        do_login(&app_state, &ctx.paths, &body.username, &body.master_password)?;
    }
    let session = UserSession {
        username: body.username.clone(),
        app_state,
        last_seen: Mutex::new(Instant::now()),
    };
    let token = ctx.store.insert(session);
    let cookie = format!("session={token}; HttpOnly; SameSite=Strict; Path=/");
    let mut res = Json(AuthSuccess { username: body.username.clone() }).into_response();
    res.headers_mut().insert(header::SET_COOKIE, cookie.parse().unwrap());
    Ok(res)
}

async fn login(State(ctx): State<AppContext>, Json(body): Json<AuthRequest>) -> Result<Response, ApiError> {
    issue_session(&ctx, &body, false)
}

async fn register(State(ctx): State<AppContext>, Json(body): Json<AuthRequest>) -> Result<Response, ApiError> {
    issue_session(&ctx, &body, true)
}
```

```rust
use pwmgr_core::session::SystemClock;
use pwmgr_web::{build_router, AppContext, SessionStore, PORT};
use std::sync::Arc;
use std::time::Duration;

#[tokio::main]
async fn main() {
    let home = dirs::home_dir().expect("could not resolve home directory");
    let paths = AppPaths::new(home.join(".pwmgr"));
    paths.ensure_app_dirs().expect("failed to create ~/.pwmgr directories");

    let ctx = AppContext { store: SessionStore::new(), paths: Arc::new(paths) };

    // Idle sweep: every 2s (same cadence as the desktop autolock::tick loop), lock idle sessions and
    // prune entries idle beyond 24h. Runs for the life of the process.

        let store = ctx.store.clone();

            let clock = SystemClock;
```

```ts
export const CLIPBOARD_CLEAR_MS = 30_000;

/**
 * Web-mode clipboard copy with a 30s auto-clear, mirroring (not sharing) the Rust
 * `copy_to_clipboard`'s `CLIPBOARD_CLEAR_SECS` behavior. `clipboard` is injectable for testing.
 * Check-before-clear: only wipes if the clipboard still holds exactly what we wrote, so a value the
 * user copied in the meantime is left alone.
 */
export async function webCopyToClipboard(
  text: string,
  clipboard: Pick<Clipboard, "writeText" | "readText"> = navigator.clipboard,
): Promise<void> {
  await clipboard.writeText(text);
  setTimeout(async () => {
    try {
      if ((await clipboard.readText()) === text) {
        await clipboard.writeText("");
      }
    } catch {
      // Clipboard unreadable (e.g. permissions) - best-effort, matching the Rust side ignoring errors.
    }
  }, CLIPBOARD_CLEAR_MS);
}
```

```ts
async function httpPost<T>(command: string, args: Record<string, unknown>): Promise<T> {
  const res = await fetch(`/api/${command}`, {
    method: "POST",
    headers: { "Content-Type": "application/json", "X-PWMGR-CSRF": "1" },
    credentials: "same-origin",
    body: JSON.stringify(args),
  });
  if (!res.ok) {
    let err: CommandError = { code: "internal_error", message: "Something went wrong. Please try again." };
    try {
      err = (await res.json()) as CommandError;
    } catch {
      // Non-JSON error body (e.g. a raw 404 from the static layer) - keep the generic fallback.
    }
    throw err;
  }
  const text = await res.text();
  return (text ? JSON.parse(text) : undefined) as T;
}
```

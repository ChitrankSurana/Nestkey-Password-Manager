# Usage Guide

All shipped features now have detailed, per-app usage guides — this file just points to them rather
than duplicating their content:

- [`HOW_TO_USE_APP.md`](HOW_TO_USE_APP.md) — current, complete reference covering all three
  interfaces (Classic/New/Make): folders, favorites, item types, password history, PIN/biometric/
  SSH unlock, and everything below, in one place.
- [`HOW_TO_USE_MAIN_APP.md`](HOW_TO_USE_MAIN_APP.md) — the Classic interface specifically, in more
  granular detail: installing, registering, vault CRUD, the four generator methods, Health
  Dashboard, Settings, Trash, backup/restore, CSV import/export.
- [`HOW_TO_USE_VIEWER_APP.md`](HOW_TO_USE_VIEWER_APP.md) — the read-only emergency-access app.
- [`HOW_TO_USE_WEB_PORTAL.md`](HOW_TO_USE_WEB_PORTAL.md) — browser access on `localhost`.

For known gaps and deferred items across all three, see
[`KNOWN_LIMITATIONS.md`](KNOWN_LIMITATIONS.md). For step-by-step manual QA procedures, see
[`testing/`](testing/).
